# 📊 Samsung Supply Chain & Logistics Dashboard (Power BI)

## 📌 Project Overview

This project presents a comprehensive **Supply Chain & Logistics Dashboard** built using **Power BI**, focusing on end-to-end operations analysis — from suppliers to customers.

The dashboard provides actionable insights into:

* Supplier performance
* Inventory management
* Shipment efficiency
* Customer revenue trends

It helps identify bottlenecks, optimize operations, and support data-driven decision-making.

## 🧠 Business Objective

The goal of this project is to:

* Monitor supply chain performance
* Identify delays and inefficiencies
* Optimize inventory and supplier selection
* Analyze revenue contribution by channels and products

---

## 📌 Key Insights

* 📦 Inventory levels peak in Q4, indicating possible overstocking
* 🚚 Shipment delays are mainly caused by carrier capacity and documentation issues
* 💰 Revenue is highly driven by online platforms like Amazon & Flipkart
* 🏭 Defective units spike during certain months, affecting supply chain efficiency
* 📊 High-value products contribute significantly to overall revenue
