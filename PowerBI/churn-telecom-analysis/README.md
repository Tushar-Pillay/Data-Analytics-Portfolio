# 📊 Milestone 4 – Retention Strategy Dashboard (Power BI)

## 📌 About This Project

This dashboard implements an end-to-end **Telecom Customer Churn Retention Strategy** using predictive churn probabilities and financial simulation.

The objective of Milestone 4 is to:

- Identify revenue at risk
- Simulate churn reduction strategies
- Measure financial impact (Revenue Saved, Campaign Cost, ROI)
- Provide interactive decision-making tools for business teams

The dashboard includes:

- Revenue at Risk calculation (probability-weighted)
- Retention impact simulation (What-If parameter)
- ROI & Net Benefit analysis
- Waterfall financial impact visualization
- Interactive filters (Contract, Tenure, Risk Tier, Persona)
