# 🏏 IPL Analysis Dashboard (2008 - 2025)

An adaptive and interactive Power BI dashboard developed to analyze Indian Premier League (IPL) seasons from 2008 to 2025. This project transforms raw cricket data into meaningful business intelligence insights using dynamic filters, KPI tracking, interactive visualizations, and sports analytics techniques.

The dashboard provides a complete season-wise analytical experience where users can dynamically select any IPL season and instantly explore team performance, player achievements, tournament statistics, points table standings, and championship summaries through an intuitive and responsive interface.

## 📌 Project Overview

The IPL Analysis Dashboard is a comprehensive sports analytics solution built using Power BI to provide season-wise insights into IPL tournaments from 2008 to 2025.

The dashboard focuses on:
- Interactive reporting
- Dynamic KPI tracking
- Team and player performance analysis
- Business intelligence visualization
- Sports data storytelling
- Adaptive dashboard design

Users can interactively select any IPL season using slicers and instantly view updated analytics across the dashboard.

This project demonstrates practical implementation of:
- Power BI Dashboard Development
- DAX Calculations
- Data Modeling
- Interactive Visualization
- Sports Analytics
- Business Intelligence Reporting

## 🎯 Project Objectives

The major objectives of this project are:

- To analyze IPL tournament data season-wise
- To build a fully interactive and adaptive dashboard

- To provide meaningful sports analytics insights

## 🚀 Dashboard Features

### ✅ Dynamic Season Filter

The dashboard includes an interactive season slicer allowing users to select any IPL season from 2008 to 2025.

Once a season is selected:
- All KPI cards update dynamically
- Points table refreshes automatically
- Orange Cap and Purple Cap statistics change instantly
- Team and player analysis updates in real time

This feature enhances:
- User interactivity
- Dynamic reporting
- Comparative analysis
- Dashboard usability

---

## 📊 KPI Metrics

The dashboard provides important tournament KPI summaries including:

- Total Matches Played
- Total Venues
- Total Teams Participated
- Total 4's Hit
- Total 6's Hit
- Total Half Centuries
- Total Centuries

These KPIs provide a quick overview of tournament performance and scoring trends for the selected season.

---

## 🏆 Season Summary Analysis

The Season Summary section displays:
- IPL Season Winner
- Runner-Up Team
- Team Logos
- Championship Overview

This section visually highlights the top-performing teams for each IPL season.

---

## 🟠 Orange Cap Analysis

The Orange Cap section identifies the highest run scorer for the selected season along with:
- Player Name
- Total Runs Scored
- Team Name
- Dynamic Player Image

This analysis helps users understand batting dominance across seasons.

---

## 🟣 Purple Cap Analysis

The Purple Cap section displays the highest wicket taker for the selected season including:
- Player Name
- Total Wickets Taken
- Team Name
- Dynamic Player Image

This feature provides insights into bowling performance and consistency.

---

## 🔥 Boundary Analysis

The dashboard includes dedicated sections for analyzing aggressive batting performances.

### Top 4's Analysis
Displays:
- Player Name
- Total 4's
- Team Name

### Top 6's Analysis
Displays:
- Player Name
- Total 6's
- Team Name

These visuals help identify the most attacking batsmen in the tournament.

---

## 📋 Dynamic Points Table

A fully interactive points table is included to display:
- Team Logo
- Team Name
- Matches Played
- Won Matches
- Lost Matches
- Tie Matches
- No Result Matches
- Total Points

The points table dynamically updates according to the selected season.
