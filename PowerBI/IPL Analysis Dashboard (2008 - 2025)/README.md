## 📌 Project Overview

This dashboard allows users to dynamically select any IPL season and instantly explore:
- Team Performance
- Points Table Analysis
- Orange Cap & Purple Cap Statistics
- Boundary Analysis
- Season KPIs
- Winner & Runner-Up Details

The project demonstrates interactive reporting, data storytelling, and business intelligence using Power BI.

---

## 🚀 Dashboard Features

### ✅ Dynamic Season Filter
- Select any IPL season from 2008–2025
- Entire dashboard updates dynamically

### ✅ KPI Metrics
- Total Matches
- Total Venues
- Total Teams
- Total 4's
- Total 6's
- Half Centuries
- Centuries

### ✅ Season Summary
- Season Winner
- Runner-Up Team
- Dynamic Team Logos

### ✅ Orange Cap Analysis
- Orange Cap Holder
- Total Runs
- Team Name
- Dynamic Player Image

### ✅ Purple Cap Analysis
- Purple Cap Holder
- Total Wickets
- Team Name
- Dynamic Player Image

### ✅ Boundary Analysis

#### Top 4's Analysis
- Player Name
- Total 4's
- Team Name

#### Top 6's Analysis
- Player Name
- Total 6's
- Team Name

### ✅ Dynamic Points Table
- Team Logo
- Team Name
- Matches Played
- Won
- Lost
- No Result
- Tie
- Total Points
